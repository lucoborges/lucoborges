## Sobre mim

Desenvolvedor focado no ecossistema **.NET**, com domínio de **C#** e **.NET 8** para criar automações e integrações. Tenho experiência sólida com **Playwright** em automação web (navegação, extração de dados e preenchimento de sistemas) e com **APIs** para conectar aplicações. Todo o trabalho é versionado com **Git** e **GitHub**.
